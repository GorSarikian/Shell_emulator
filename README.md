# Shell Emulator

Эмулятор командной строки UNIX-подобной операционной системы.

## 1. Общее описание
Проект представляет собой минимальный прототип командной оболочки (REPL).
Поддерживает диалог с пользователем, интерактивный ввод команд,
парсинг аргументов и базовую обработку стандартных сигналов завершения.

## 2. Описание всех функций и настроек
- `main.py`: точка входа, принимает имя виртуальной файловой системы (VFS)
  в качестве аргумента командной строки (по умолчанию: `my-vfs`).
- `src/cli.py`: реализация консольного цикла REPL (`ShellCLI`),
  формирование приглашения ко вводу и обработка прерываний ввода.
- `src/parser.py`: парсер входной строки, разделяющий имя команды и аргументы.
- `src/commands.py`: диспетчер команд и заглушки:
  - `ls`: выводит свое имя и переданные аргументы.
  - `cd`: выводит свое имя и аргументы перехода.
  - `exit`: завершает выполнение оболочки с проверкой кода возврата.
